Available tools:
- search_shipwrecks: Search MongoDB shipwreck records by exact category and/or water level (case-insensitive). Examples: feature_type='Wrecks - Visible' or 'Wrecks - Submerged, dangerous'; water_level='always dry'. Empty filters match all. limit is 1 to 20, default 3. Returns a sample and matched_count, not every matching record. Depth units are unspecified; zero/unknown depth is not a confirmed measurement.
- get_statistics: Read Redis counts calculated from the complete supplied shipwrecks.json. key='shipwreck_summary' returns total records, counts by feature type and depth-quality counts. key='water_level_counts' returns counts by water level. These are dataset records, not live app users or global wreck totals.
